Garden Guard is a bright golden-hour tower defence built on cross-pollination: plant different flowers side by side and they grow stronger together — all three together make a Rainbow Bed — then loose the bee swarm when the pests pile up, and hold 10 waves to save the harvest.
## Run it
```sh
npx serve game
```
Then open the printed address in a desktop browser. No build step, no network — the game is plain static files.
## How to play
- Pick a flower (buttons or keys 1 / 2 / 3), then click a grass cell to plant it. Flowers cost nectar; killing pests earns more.
- Click a planted flower to upgrade it (★ levels) or sell it back for 70%.
- Space sends the next wave. B releases the Bee Swarm. P pauses, M mutes, R restarts.
- Every pest that reaches the garden gate costs 1 life. Lose all 20 lives and the harvest is gone; clear wave 10 — including the Queen Aphid — and the garden is saved.
